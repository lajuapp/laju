# Backoffice Conversations

## Personal

Authorized operators may see:

- participants
- device state
- lifecycle metadata
- security events
- message content only after controlled access approval

## Group

Authorized operators may see:

- group metadata
- members/roles
- membership events
- lifecycle metadata
- message content only after controlled access approval

## Content access

Content access requires:

- permission
- MFA/step-up
- separate access secret
- optional dual approval
- time limit
- audit

Do not create a universal decryption master key.
