# Data Classification

## Critical secret

- private keys
- E2EE session secrets
- conversation access secrets
- attachment decryption keys

## Highly sensitive

- message plaintext
- precise location
- admin credentials
- security events

## Sensitive

- message ciphertext
- device identifiers
- group membership
- call metadata

## Operational

- health metrics
- request IDs
- service status

Each class has separate access and retention rules.
